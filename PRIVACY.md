# InforMed Upload: Privacy Policy

_Last updated: 26 September 2026_

InforMed Upload is the private automation tool that publishes content for the InforMed Lab channels (YouTube, Instagram, Facebook and TikTok). It is operated by InforMed Lab for its own accounts only and is not offered to the public.

**What it accesses.** With the account owner's authorization, the tool uses the YouTube Data API and YouTube Analytics API (and the equivalent Meta and TikTok APIs) to upload and schedule InforMed Lab's own videos, set their thumbnails, and read performance statistics for InforMed Lab's own channel.

**What it stores.** OAuth refresh tokens are stored encrypted as GitHub Actions secrets in the project repository and are used only to perform the actions above. Performance statistics for InforMed Lab's own content are stored in the project repository to improve future content. No data about viewers or any other users is collected, sold or shared.

**Google API Services.** InforMed Upload's use and transfer of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

**Revoking access.** The account owner can revoke access at any time at https://myaccount.google.com/permissions.
